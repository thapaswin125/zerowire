CVE ID : CVE-2026-97353 Published : Oct. 24, 2026, 6:16 a.m. | 54 minutes ago Description : The News Kit Addons For Elementor WordPress plugin through 1.4.7 does not perform capability or ownership checks before updating post metadata in one of its authenticated AJAX actions, allowing users with subscriber-level access and above to write arbitrary post meta, under attacker-chosen keys, to any post including those owned by other users.
