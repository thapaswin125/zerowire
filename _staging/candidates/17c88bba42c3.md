CVE ID : CVE-2026-113490 Published : Oct. 24, 2026, 6:16 a.m. | 54 minutes ago Description : The GeoDirectory WordPress plugin before 2.8.194 does not perform any status or ownership check when rendering a listing's map-popup through one of its single-item REST routes, allowing unauthenticated users to read the title, permalink and card fields of non-public (draft, pending, private and trashed) listings by supplying the listing ID.
