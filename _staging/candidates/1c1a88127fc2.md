CVE ID : CVE-2026-62236 Published : July 17, 2026, 2:18 a.m. | 2 hours, 44 minutes ago Description : grav-plugin-login before 3.8.11 contains a cross-site request forgery (CSRF) vulnerability in the login.regenerate2FASecret frontend task, which regenerates and persists a new TOTP secret for the authenticated session user without any anti-CSRF nonce or Origin/Referer check.
