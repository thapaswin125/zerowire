CVE ID : CVE-2026-84097 Published : Sept. 26, 2026, 7:17 a.m. | 1 hour, 2 minutes ago Description : The wp-review-slider-pro WordPress plugin before 12.7.12 does not sanitize a value stored through one of its AJAX handlers, which lacks a capability check, before using it in a SQL statement, allowing any authenticated user, such as a subscriber, to perform SQL injection attacks whose results are then returned to unauthenticated visitors.
