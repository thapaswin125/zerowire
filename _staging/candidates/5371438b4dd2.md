CVE ID : CVE-2026-90668 Published : Sept. 13, 2026, 2:17 a.m. | 6 hours, 36 minutes ago Description : The webserver in UnrealIRCd 6.0.5 through 6.2.6 before 6.2.7 does not limit the number of HTTP request headers, which allows remote attackers to cause a denial of service (memory consumption and unresponsive server) via an HTTP request with an unlimited number of headers, if a websocket or JSON-RPC listener is enabled (disabled by default).
