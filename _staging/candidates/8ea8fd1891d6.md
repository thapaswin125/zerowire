CVE ID : CVE-2026-92411 Published : Sept. 26, 2026, 7:17 a.m. | 1 hour, 2 minutes ago Description : The WP Delicious WordPress plugin before 1.10.8 does not validate or escape the HTML tag name taken from user-supplied recipe block data before rendering it on the front end, allowing users with the Contributor role and above to inject arbitrary HTML tags, including script tags, which execute when the recipe page is viewed.
