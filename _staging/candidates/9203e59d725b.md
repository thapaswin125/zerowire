CVE ID : CVE-2025-11455 Published : Oct. 31, 2026, 8:16 a.m. | 23 minutes ago Description : The Perfect Images plugin for WordPress is vulnerable to unauthorized modification of data due to a missing capability check on the /wp-json/wp-retina-2x/v1/replace REST API in all versions up to, and including, 7.2.0 This makes it possible for authenticated attackers, with Author-level access and above, to replace files that do not belong to them.
