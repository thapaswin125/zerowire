CVE ID : CVE-2026-62233 Published : July 17, 2026, 2:18 a.m. | 2 hours, 44 minutes ago Description : grav-plugin-api before 1.0.6 fails to validate super-admin status in createApiKey, generate2fa, and disable2fa endpoints, allowing non-super api.users.write managers to escalate to super-admin. Attackers can mint API keys bound to super-admin accounts or strip 2FA from super-admin users to achieve full instance takeover.
