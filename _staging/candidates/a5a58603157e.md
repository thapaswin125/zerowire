CVE ID : CVE-2026-92433 Published : Oct. 17, 2026, 6:16 a.m. | 2 hours, 24 minutes ago Description : The Patreon WordPress plugin before 1.10.0 does not verify a nonce when connecting the site to a Patreon account, allowing attackers to make a logged-in administrator re-link the integration to an attacker-controlled account via a crafted request (CSRF), taking over the site's Patreon integration.
