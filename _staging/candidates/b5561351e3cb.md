CVE ID : CVE-2026-48806 Published : July 14, 2026, 9:28 p.m. | 48 minutes ago Description : Twig is a template language for PHP. Prior to 3.27.0, ArrayExpression does not guard dynamic mapping keys that are coerced to strings, allowing PHP to invoke __toString() on a Stringable object used as a mapping key without calling SandboxExtension::ensureToStringAllowed().
