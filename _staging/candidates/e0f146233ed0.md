CVE ID : CVE-2026-19860 Published : Sept. 19, 2026, 6 a.m. | 56 minutes ago Description : The JetFormBuilder — Dynamic Blocks Form Builder WordPress plugin before 3.6.5.3 does not sufficiently restrict which PHP functions can be used as a custom field-validation callback, relying on a blocklist that omits a file-deletion function, allowing users able to manage forms to cause arbitrary files on the server to be deleted.
