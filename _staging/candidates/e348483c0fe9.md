CVE ID : CVE-2026-71883 Published : Oct. 3, 2026, 9:17 a.m. | 22 minutes ago Description : In Bouncy Castle for Java LTS before 2.73.13, the one-shot native packet ciphers for AES-CBC, CCM, CFB, CTR, GCM and GCM-SIV released the caller's key, IV and additional authenticated data arrays with JNI's ReleaseByteArrayElements in mode 0, which commits the native copy back into the Java array.
