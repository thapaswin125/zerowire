CVE ID : CVE-2026-113491 Published : Oct. 24, 2026, 6:16 a.m. | 54 minutes ago Description : The GeoDirectory WordPress plugin before 2.8.194 does not validate a user-supplied image URL before using it as a local file path when saving a front-end listing, allowing users with Subscriber-level access and above to read files from outside the web root and to delete files on the server, limited to file names that carry an allowed media extension.
